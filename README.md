## 📌 Overview
**CS Survival Sim** is an interactive, audio-reactive resource management web game built to simulate the high-stakes grind of a Computer Science undergrad's final project. Players must balance their energy, code quality, and sanity over 14 in-game days to submit a flawless build to Dr. Sennaike, all while managing the heavy risks of Turnitin similarity scores.

This project was built to demonstrate proficiency in modern frontend development, complex state management, and UI/UX design.

## ⚙️ Core Mechanics & Features
- **Dynamic State Management:** Built with React `useState` and `useEffect` hooks to manage interconnected variables (Energy, Sanity, Code Quality, Similarity) that react instantly to user input.
